# Patch queue (Nisse fork)

Only approved DSH core patches live here. Each patch is a directory `PATCH.md` +
the patch file, with purpose, affected files, upstream baseline, tests, owner,
removal condition and rebase notes.

Current policy: **M1/M2 freeze = no DSH core patches**. Route A orchestration and
Host Integration live outside the core. Any future patch requires user approval
and a re-opened ADR-0005 decision.
